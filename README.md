# 致 妳

一个只写给两个人的纪念页。手机、平板、电脑都能正常打开。

## 怎么改成你们自己的内容

打开 **`script.js`**，最上面有个 `CONFIG`，改这一个地方，整站内容全跟着变。

### 1. 纪念日（最重要）

```js
startDate: "2023-05-20T20:20:00"
```

改成你们真正在一起的那一天。首页那个大数字「第 N 天」就是按它实时算的，每秒刷新。

### 2. 故事时间轴

```js
story: [
  { date: "2023.05.20", title: "第一次见面", text: "……" },
  ...
]
```

想加几条就加几条，想删就删。最后一条带 `now: true` 的会显示成红色实心圆点，表示"现在"。

### 3. 关于妳的十件小事

`little` 数组里每行一条。标题写的是十件，但真正是几条由数组决定，你想写二十条也行（记得顺手改一下 `index.html` 里的标题）。

### 4. 那封信

`letter` 数组，每个字符串是一段，会自动首行缩进。

### 5. 放照片

把照片改名成 `1.jpg`、`2.jpg` …… 放进 `photos/` 文件夹，就会自动出现在照片墙。

- 建议竖图（3:4 比例最贴合版式）
- 建议每张先压到 300KB 以内，手机流量打开更快
- 数量默认 6 张，要改的话改 `photoCount`

## 本地预览

双击 `index.html` 就能看。想更接近线上效果（照片能正常加载），在本目录执行：

```bash
python -m http.server 8080
```

然后浏览器打开 http://localhost:8080

## 文件说明

```
index.html   页面结构
style.css    全部样式
script.js    内容配置 + 交互逻辑（只改这个）

```
